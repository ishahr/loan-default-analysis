# Loan Default Risk Analysis

Analysis of a 255,000+ row loan dataset to identify key predictors of borrower default, using Excel and pivot tables.

## Key Findings
- Overall default rate: 11.6%
- **Income is a strong predictor**: Low-income borrowers default at 22.0% vs 9.4% for high-income (2x+ difference)
- **Credit score has a weaker effect**: 12.5% (low) vs 10.2% (high) — a much smaller gap than expected

## Tools Used
Excel, Google Sheets (Pivot Tables, Formulas)
